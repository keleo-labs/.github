# .github

Organisation-level repository for [keleo-labs](https://github.com/keleo-labs).

## What this repo does

On GitHub, a repository named `.github` serves a special role for an organisation:

- **Organisation profile** — [`profile/README.md`](profile/README.md) is rendered on the [keleo-labs organisation page](https://github.com/keleo-labs).
- **Community health files** — default issue templates, pull request templates, contributing guidelines, and code of conduct that apply across all repositories in the organisation.
- **Reusable workflow templates** — GitHub Actions workflows that other repositories can reference.

## Contents

| Path | Purpose |
|---|---|
| `profile/README.md` | The public-facing Keleo project overview displayed on the organisation page |
